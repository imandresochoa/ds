# Primitivas de la interfaz

Piezas base de la interfaz del kit, tomadas de [shadcn/ui](https://github.com/shadcn-ui/ui) (`apps/v4/registry/new-york-v4/ui`). Solo construyen el shell del kit: ningún sistema las documenta ni las instala.

Se mantienen cerca del original para poder actualizarlas comparando con shadcn. Los únicos cambios son las rutas de importación (`@/lib/utils`, `@/components/ui/*`).
