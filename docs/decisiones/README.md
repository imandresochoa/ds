# Decisiones del kit

Una decisión por archivo, numeradas (`NNNN-slug.md`), con el formato de `docs/metodologia/11-decisiones.md`: frontmatter con `estado`, `fecha`, `decide`, `afecta` y `sustituye`, y los apartados Contexto, Decisión, Consecuencias y Alternativas.

Un agente las escribe en estado `propuesta`. Solo una persona las pasa a `aceptada` o `rechazada`, con su nombre en `decide`.

Las decisiones anteriores al 2026-11-19 están en el histórico, [`../DECISIONES.md`](../DECISIONES.md), que ya no se amplía.
